# 安全与隐私

## 原则

**最小权限 + 本地优先 + 按需联网 + 可回退 + 可审计。**

## Zotero

- 不直接读写 `zotero.sqlite` 做业务操作。
- 原 PDF 只读。
- Local API 只绑定 localhost，不转发端口。
- 真实写操作需要用户明确命令、修改预览和 Zotero 本地授权。

## Obsidian

- 只读当前主题目录。
- 写入前先生成提案。
- 用户确认后才写。
- 正式知识与中间产物分离。

## 网络

- 主论文不自动联网找全文。
- 深度精读外部对比才按需联网。
- 不把整个 Vault 或私人批注作为外部搜索输入。

## 日志

建议只记录：

- citekey
- 状态
- 路径
- 时间
- 操作结果

不要在日志里复制整篇论文全文。

## Git

- 工作区建议纳入 Git。
- Obsidian Vault 可单独纳入 Git。
- PDF 和大附件默认忽略。
- 写入前后查看 `git diff`。
