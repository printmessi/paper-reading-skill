# 模块 06：论文类型与分析重点

允许多标签混合。分类目的是切换阅读重点，不是给论文贴死标签。

## 理论 / 数学建模类

重点：假设、定义、定理/命题、推导链、边界条件、适用范围、数值/仿真验证。

## 算法 / AI / 信号处理类

重点：问题定义、输入输出、模型/算法结构、损失函数、复杂度、数据集、baseline、消融、泛化、参数敏感性。

## 实验 / 测量类

重点：实验设计、变量控制、样本、仪器、标定、重复次数、误差、不确定度、统计方法、测量条件。

## 硬件 / 系统实现类

重点：系统架构、关键器件、接口、带宽/功耗/延迟/精度、实现约束、测试平台、系统级权衡。

## 材料 / 器件类

重点：材料/器件制备、表征手段、机理、实验条件、性能指标、对照组、稳定性、重复性、制造约束。

## 控制 / 通信 / 工程系统类

重点：系统模型、假设、控制/估计/调制策略、稳定性、鲁棒性、信道/噪声模型、仿真与实测一致性。

## 综述 / Review / Survey

不要用普通论文模板硬套。重点提取：

- taxonomy / 分类体系
- 技术路线演化
- 各路线代表方法和核心差异
- 常见数据集/指标/实验平台
- 各路线优缺点
- 当前争议和未解决问题
- 作者明确提出的未来方向
- 最值得作为入门路线阅读的章节

## 混合类型

例如 `算法 + 实验`：既分析算法设计，也检查实验条件与测量可信度。
