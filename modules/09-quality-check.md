# 模块 09：轻量质量自检

## 使用时机

- 用户说“检查当前论文流程”
- 正式写入 Obsidian 前
- 实际更新 Zotero 前

## 检查清单

### 主论文

- [ ] 当前主论文 PDF 实际存在且可读取
- [ ] 若扫描版/解析异常，已显式标记
- [ ] 没有用外部网页替代主论文全文

### 内容可靠性

- [ ] 核心论点有原文定位
- [ ] 关键公式/图表有定位
- [ ] 数值能核验
- [ ] 作者观点与 AI 分析已分开
- [ ] “我的理解”只来自用户
- [ ] 无法确认的地方已标 `暂无/待核验`

### 深度精读

- [ ] 论文类型已识别
- [ ] 教学部分和科研分析部分完整
- [ ] 关键公式按要求解释
- [ ] 实验与主张之间的关系被检查
- [ ] 外部对比来源完整
- [ ] active recall 问题已生成

### 状态与文件

- [ ] citekey/item key 可唯一识别
- [ ] 研究主题已绑定
- [ ] 主题内编号无冲突
- [ ] 状态文件已更新

### 写入安全

- [ ] Obsidian 只涉及指定主题目录
- [ ] 已生成 knowledge-update-proposal
- [ ] 用户已明确确认 Obsidian 写入
- [ ] Zotero 修改由用户明确下令
- [ ] Zotero 写入走安全接口，不碰 SQLite
- [ ] Git diff/备份可用于回退
